# Network Traffic Analysis with Wireshark

A beginner cybersecurity project that analyzes network traffic to identify DNS, HTTP, and suspicious domain requests using Wireshark.

### Skills Used

* Wireshark
* Packet Analysis
* DNS Investigation
* Network Security

### Project Files

* `capture.pcap` — Sample packet capture
* `analysis_report.pdf` — Investigation report
* `screenshots/` — Evidence from Wireshark

### Key Findings

* Identified WPAD requests
* Analyzed DNS responses
* Investigated suspicious domains
* Distinguished normal Microsoft traffic from unusual traffic
